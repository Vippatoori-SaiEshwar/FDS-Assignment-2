# FDS Assignment 1: Case Study 6
## Comparative Analysis of Classification Algorithms for Bank Marketing Prediction

This project compares Logistic Regression, Decision Tree, K-Nearest Neighbours (KNN), and Random Forest for predicting whether a customer subscribes to a term deposit.

### Dataset
- `bank-full.csv`: Bank Marketing dataset, loaded with a semicolon (`;`) delimiter.
- Target: `y` (`yes` = subscribed, `no` = not subscribed).
- `duration` is excluded from the primary models because it is only known after the current call.

### Methodology
- Exploratory data analysis and target distribution.
- Stratified 80:20 train-test split (`random_state=42`).
- Median imputation and scaling for numeric features.
- Most-frequent imputation and one-hot encoding for categorical features.
- Four classification models compared using accuracy, precision, recall, F1-score, confusion matrices, and ROC-AUC.
- Confusion matrices and ROC curves are included in the notebook.

### Files
- `Case_Study_6_Bank_Marketing_Classification.ipynb`: Executed notebook with code, outputs, graphs, and interpretations.
- `Case_Study_6_Bank_Marketing_Report.docx`: Report draft for review and submission.
